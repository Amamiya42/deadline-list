# deadline清单 v1.1 子任务功能设计文档

> 状态：已通过与用户确认，待进入 implementation plan
> 日期：2026-08-23

## 1. 背景与目标

v1 的 deadline清单只支持单层任务。用户在 v1.1 中需要把一个大 deadline 拆成多个子 deadline，形成树状结构，从而：
- 子任务可独立设置 deadline
- 子任务参与全局紧迫度排序
- 子任务可独立提醒、独立撕成桌面便签
- 父任务与子任务的完成状态双向联动

## 2. 数据模型

任务扁平化存储，新增两个字段：

```js
{
  id: string,
  name: string,
  deadline: number,
  notes: string,
  done: boolean,
  completedAt: number | null,
  notified: object,
  note: object | null,
  parentId: string | null,   // null = 根任务；否则指向父任务 id
  expanded: boolean          // 在主面板中是否展开显示子节点（UI 状态）
}
```

- 所有节点共用同一 schema，不再区分“任务”与“子任务”。
- `parentId` 指向父节点，形成任意层级的树。
- `expanded` 只影响 UI 展示，不参与业务逻辑。

### 2.1 数据迁移

`loadData()` 读取旧 `data.json` 时，对缺少 `parentId` 的旧任务自动补 `parentId: null`，对缺少 `expanded` 的补 `expanded: true`。

## 3. 完成状态联动

双向联动：

- **父 → 子**：用户标记父任务完成时，递归标记所有后代节点为完成。
- **子 → 父**：当某个节点的所有直接子节点都完成时，该节点自动标记完成（递归向上传播）。
- **撤销完成**：`uncomplete-task` 只影响当前节点，**不**自动撤销父节点，防止误操作把整棵树恢复。

父任务可以独立存在 deadline，也可以有自己的便签、提醒。

## 4. 主面板 UI

### 4.1 树形列表

- 所有未完成节点按 `deadline` 升序全局混排。
- 每个节点前显示 ▶/▼ 展开折叠按钮；点击切换 `expanded`。
- 每级缩进 18px。
- hover/选中时任务卡片显示「+」按钮，点击在当前节点下新增一个子任务。
- 右键菜单：添加子任务 / 编辑 / 删除 / 撕成便签 / 标记完成。
- 双击任务打开编辑面板。

### 4.2 已完成区

已完成区保持平铺，按 `completedAt` 倒序，不再展示层级缩进（避免已完成树过于复杂）。

## 5. 编辑面板

双击任务后，编辑面板包含：

- 当前任务：任务名、deadline、备注
- 子任务区块：
  - 子任务列表（名称 + deadline + 完成 checkbox）
  - 「添加子任务」按钮
  - 每个子任务右侧的删除按钮
  - 子任务名称/deadline 可就地编辑

## 6. 横幅

横幅显示全局最紧迫的未完成节点（根或子）。

若最紧迫节点是子任务，显示格式：

```
最紧迫的未完成任务
[根任务名] > ... > 子任务名
还剩 X 小时 · 子任务截止 ...
根任务截止 ...
```

感叹号规则沿用现有 `exclamations()` 逻辑。

## 7. 便签

任何节点均可撕成独立桌面便签。便签窗口只显示该节点自身信息，不展开其子孙。

`noteWins` 的 key 仍是节点 id，无需改动映射语义。

## 8. 提醒系统

每个节点独立走四节点提醒（T-3天/T-24h/T-1h/T-0），独立维护 `notified` 对象。

`checkReminders()` 遍历 `data.tasks` 中所有 `done === false` 的节点即可。

## 9. 删除规则

- 删除父任务 → 递归删除其所有后代节点。
- 删除子任务 → 如果父任务因此不再有任何子任务，父任务自动降级为普通叶子任务（无需额外字段变更，只是逻辑上不再被视为父节点）。

## 10. 受影响的文件

- `main.js`：IPC 新增/调整；完成联动递归；删除递归；提醒遍历所有节点；横幅取全局最紧迫节点并追溯根路径。
- `preload.js`：暴露新增 IPC。
- `renderer/common.js`：新增树遍历/根路径查找工具函数。
- `renderer/panel.js`：树形渲染、展开折叠、右键菜单、+ 按钮、编辑面板子任务区。
- `renderer/panel.html/css`：树形样式、编辑面板子任务区样式、计数器样式。
- `renderer/note.js`：无改动（节点语义不变）。

## 11. 非目标

- 拖拽排序子任务（v1.1 不做）
- 子任务分类/标签（v1.1 不做）
- 子任务批量导入导出（v1.1 不做）
